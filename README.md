# Лекции по ООП (Java) — Явор Томов

Записки от лекциите за випуск 23 (233/234/235), УКТЦ. Статичен сайт за GitHub Pages.

## Как да добавиш лекция

1. Сложи `.md` файла в `lections/`, кръстен на датата на лекцията — напр. `30-10.md`.
2. Добави го в `lections/lections.json`:
   ```json
   { "file": "30-10.md", "title": "Заглавие на лекцията", "date": "2026-10-30" }
   ```
   Лекцията с най-новата дата се показва на началната страница.
3. Снимките слагай в `img/` и ги вмъквай така: `![описание](../img/snimka.png)`.

## Добавки към лекцията

Текстът на лекцията остава както е казан в час. Всичко добавено отгоре (примери, уточнения) е в отделни карета с етикет „добавено“:

```md
> [!TIP]
> Пример, който помага да се разбере темата.

> [!NOTE]
> Уточнение, ако нещо в записките е неточно или непълно.
```

Математика се пише с `$...$` (напр. `$\rightarrow$`).

## Локално

```bash
python -m http.server 8000
```

После отвори http://localhost:8000 (директно отваряне на `index.html` не работи, защото сайтът зарежда `.md` файловете с `fetch`).
