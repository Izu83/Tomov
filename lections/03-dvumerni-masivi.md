# Двумерни масиви

> Примерна лекция за демото — замени я със записките от часа.

## Как изглеждат

Двумерният масив е **масив от масиви**. Първият индекс е редът, вторият — колоната.

![Двумерен масив — редове и колони](../img/matrix.png)

```java
int[][] arr = new int[4][4];   // 4 реда, 4 колони
arr[0][2] = 7;                 // ред 0, колона 2
```

Може и директно със стойности:

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

## Обхождане

```java
for (int row = 0; row < matrix.length; row++) {
    for (int col = 0; col < matrix[row].length; col++) {
        System.out.print(matrix[row][col] + " ");
    }
    System.out.println();
}
```

- `matrix.length` — броят **редове**.
- `matrix[row].length` — броят **колони** в конкретния ред.

## Назъбени масиви (jagged)

Понеже всеки ред е отделен масив, редовете може да са с различна дължина:

```java
int[][] jagged = new int[3][];
jagged[0] = new int[1];
jagged[1] = new int[3];
jagged[2] = new int[2];
```
