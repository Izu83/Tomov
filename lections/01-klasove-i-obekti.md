# Класове и обекти

> Примерна лекция за демото — замени я със записките от часа.

## Какво е клас?

**Класът** е шаблон (чертеж), който описва какви **данни** (полета) и какво **поведение** (методи) ще имат обектите. **Обектът** е конкретна инстанция на този клас, създадена с `new`.

```java
public class Student {
    String name;
    int grade;

    void introduce() {
        System.out.println("Аз съм " + name + " от " + grade + " клас.");
    }
}
```

```java
Student ivan = new Student();
ivan.name = "Иван";
ivan.grade = 11;
ivan.introduce(); // Аз съм Иван от 11 клас.
```

## Конструктори

Конструкторът се извиква при `new` и задава началното състояние на обекта. Има същото име като класа и **няма** тип на връщане.

```java
public class Student {
    String name;
    int grade;

    public Student(String name, int grade) {
        this.name = name;   // this.name е полето, name е параметърът
        this.grade = grade;
    }
}
```

- Ако не напишем конструктор, Java добавя празен конструктор по подразбиране.
- Щом напишем свой конструктор, празният **изчезва**.

## Референции

Променливата от тип клас пази **референция** към обекта, а не самия обект.

```java
Student a = new Student("Мария", 11);
Student b = a;      // b сочи към СЪЩИЯ обект
b.grade = 12;
System.out.println(a.grade); // 12
```

## Запомни

| Понятие | Накратко |
|---|---|
| Клас | Шаблон — полета + методи |
| Обект | Инстанция на клас (`new`) |
| Конструктор | Задава начално състояние |
| `this` | Текущият обект |
